# Identidad del fork — JoseloFarias

Este repositorio forma parte de los forks mantenidos por **JoseloFarias**.

## Identidad

- Mantenedor del fork: **JoseloFarias**
- Marca de distribución: **JoseloFarias**
- Nombre de la aplicación: **NewTermux**
- El sufijo `-byte` pertenece únicamente al nombre actual de la cuenta de GitHub y **no forma parte de la marca**.
- Toda nueva UI, metadato, artefacto de release y documentación propia debe usar `JoseloFarias` de forma consistente.

## Compatibilidad y paquetes

La identidad técnica del paquete Android debe permanecer única respecto del upstream cuando el fork ya esté independizado. Cualquier cambio de `applicationId`, `namespace`, authorities, deep links o permisos con nombre de paquete debe hacerse de forma atómica y verificarse mediante build e instalación.

## Créditos y licencia

Este fork deriva de Termux y conserva las atribuciones, avisos de copyright y licencia aplicable. La marca JoseloFarias identifica únicamente las modificaciones y builds de este fork. Cuando corresponda, se debe dirigir a los usuarios al proyecto original para reconocer o apoyar a sus autores.

## Regla visual

Los recursos propios del fork deben mantener una identidad visual coherente entre icono, splash, pantallas Acerca de, README y releases. No se deben reutilizar logotipos o marcas del upstream como si fueran propiedad del fork.
