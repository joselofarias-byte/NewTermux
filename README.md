# NewTermux — JoseloFarias fork

Proyecto Android/Termux mantenido por **JoseloFarias** para experimentar con una experiencia de terminal moderna sin romper compatibilidad con flujos existentes.

## Objetivos

- Mantener compatibilidad con Android y Termux actuales.
- Priorizar estabilidad, seguridad y continuidad del entorno del usuario.
- Evitar reconstrucciones de toolchain innecesarias y cambios destructivos.
- Conservar atribuciones y licencia del proyecto de origen.

## Estado

Proyecto en desarrollo/evaluación activa.

## Desarrollo

```bash
git clone https://github.com/joselofarias-byte/NewTermux.git
cd NewTermux
./gradlew assembleDebug
```
